# AFTERGLOW

純靜態 Spotify Extended Streaming History 分析網站。Three.js 舞台、原生 JavaScript、Vite、fflate；沒有後端、帳號或資料儲存。

## 本機開發

```sh
npm ci
npm run dev
```

開啟終端顯示的本機網址。可先按「探索示範」；按「獲取播放記錄」展開教學後匯入 Spotify 原始 ZIP，也可直接拖放到聲波。上傳與解析進度位於同一個入口區塊底部。

## 建置與部署

```sh
npm test
npm run build
npm run preview
```

將 `dist/` 部署到任何靜態 HTTP 主機（例如 GitHub Pages、Cloudflare Pages）。資產使用相對路徑，支援子目錄部署。請透過 HTTP/HTTPS 開啟，Web Worker 無法直接從 `file://` 運作。需要支援 ES modules、Web Workers、File.stream() 的現代瀏覽器；無 WebGL 時仍可分析，3D 改用靜態背景。

## 功能

- 本機 ZIP 驗證、逐檔解壓與背景統計，顯示階段、進度、取消和錯誤重選。
- 自訂最低播放秒數（0–600，預設 30）、排除跳過播放、歌曲／歌手名稱包含規則（每行一個關鍵字，不分大小寫）。修改匯入條件需重新匯入。
- 年度與月份時數和播放次數、星期 × 小時熱圖及其時數／次數明細。
- 每年及歷年歌曲／最愛歌手排行，可按時數或次數排序，兩個數值同時顯示。
- 排行榜歌曲可點進明細，歌手可點進歌曲清單。歌曲明細可排除歌曲／歌手，重算所有年份與圖表，可逐項或全部還原，不修改原始 ZIP。
- 依歌曲／歌手搜尋，搭配獨立日期區間，分頁列出聽過的歌曲。點選可查看區間內首次／末次記錄、播放次數、時數和逐年分布。
- TripEZGo 深色品牌配色和頁尾廣告；圖示隨網站一同部署，分析不需連線 TripEZGo。
- 聲波顯示目前範圍最常聽的歌曲與歌手，依時數排序，隨年份與排除更新。
- 廣告上方的「分享出去」直接顯示多張分享圖，可切換 1080×1350 直式或 1080×1080 正方形；每張均提供分享與 PNG 下載。圖片跟隨年份、排行榜排序、搜尋日期與明細更新。年份直接寫入標題，不顯示排除條件。底部只放 TripEZGo Icon 和 TripEZGo.com。
- 系統圖片分享需要 HTTPS 或 localhost；不支援時提供 PNG 預覽與下載。網站不自動傳送圖片。
- 作者示範資料為使用者授權提供的播放歷史，已移除 `Stuck with U (with Justin Bieber)`，只包含歌曲識別、名稱、歌手、專輯、播放時間及時長，不包含 IP／連線資訊。壓縮資料位於 `public/demo-history.json.gz`，可用 `node scripts/build-demo.mjs <匯出資料夾>` 重新產生。

## 計算與隱私

只統計歌曲，以 `ms_played` 加總；每筆符合條件的歌曲播放算一次。預設排除不足 30 秒，恰好 30 秒保留。門檻為 0 時也會納入 0 秒播放。排除順序為非歌曲／格式無效、秒數門檻、跳過標記、名稱條件，各筆只計入一個排除分類。

依瀏覽器時區，整筆播放歸入 `ts` 所在日期／小時，不拆分跨日播放。首次／末次聆聽代表匯出資料中符合目前條件的記錄時間，不推估精確開始時間。日期篩選包含結束日整天。不同 Spotify URI 的歌曲版本分別計算；缺少 URI 時以曲名、歌手、專輯組合作為識別。歌手依匯出的名稱分組，不推測合作歌手。

不將播放記錄上傳、不寫入 localStorage／IndexedDB／資料庫；只在分頁記憶體保留分析所需的歌曲欄位，IP 等無關欄位不保留。清除、關閉或重新整理後需重新匯入。網站本身的靜態檔案可依主機設定被瀏覽器快取，播放記錄不包含在其中。

ZIP 上限 256 MiB，單個解壓 JSON 上限 64 MiB，總解壓上限 1 GiB。第一版不提供 Podcast、有聲書、曲風、登入或永久儲存。匯入同一份完整匯出，避免重複檔案造成重複統計。

## 驗證

`npm test` 涵蓋門檻、時區歸組、排除重算、日期區間、首次／末次、ZIP Worker、錯誤格式及作者示範資料。另以提供的實際 ZIP 完成瀏覽器匯入及獨立數值核對；分享圖已驗證兩種尺寸與年份標題。原始匯出 ZIP 不納入建置，只包含作者授權的精簡示範資料。
