# 已確認的產品決策

使用者已確認規格並授權實作；以下包含開發過程中追加的需求。

- 純靜態網站；ZIP 解壓縮、分析、搜尋都在瀏覽器完成，不上傳或永久保存播放記錄。
- Three.js 電音祭典視覺搭配清楚圖表；沿用 TripEZGo 的青綠／暖黑深色品牌色，頁尾加入 TripEZGo 廣告連結。
- 匯入前檢查副檔名、ZIP 標頭與結尾目錄、JSON 與 Spotify 資料欄位；提供分析中階段、進度、取消與具體錯誤。
- 入口整合為單一 SPOTIFY LISTENING EXPERIENCE；先點「獲取播放記錄」展開教學，再按匯入，也可直接將 ZIP 拖到聲波。上傳／解析進度位於此區塊底部。
- 提供七步驟下載教學，從 Spotify 隱私設定申請「長期串流播放記錄」，點「申請資料」後到信箱收取確認信完成申請，收到下載通知後下載 `my_spotify_data.zip`。
- 第一版只分析歌曲，略過 Podcast／有聲書，不提供曲風分析。
- 匯入條件由使用者控制：最低播放秒數 0–600（預設 30）、是否排除跳過、歌曲／歌手名稱包含關鍵字。修改後需重新匯入。恰好達門檻者保留，設為 0 時包含 0 秒播放。
- 實際時數以播放毫秒數加總；每筆符合條件的歌曲算一次播放。年度／月份、排行、熱圖明細、搜尋與歌曲明細均顯示時數及次數。
- 使用瀏覽器時區，整筆歸入記錄時間所在的小時／日期，不拆分跨時段播放。
- 提供每年／每月圖表、星期 × 小時熱圖、歌曲／最愛歌手排行；排行支援年度與歷年總榜，時數／次數排序。
- 排行榜歌曲可開啟完整明細，歌手可點進歌曲清單；歌曲明細提供排除歌曲或該歌手全部歌曲，套用至所有年份與所有圖表，可逐項／全部還原。排行榜不顯示排除按鈕，不修改原始 ZIP。
- 可依歌曲或歌手搜尋及獨立日期區間列出聽過的歌曲；點選查看區間內的逐年分布、總時數／次數、首次／末次記錄。日期區間包含結束日整天，沿用匯入條件與排除清單。
- 提供作者授權的精簡播放歷史作為示範，排除 Stuck with U (with Justin Bieber)，不含 IP／連線資訊。移除清除重選按鈕與手動動態開關；仍尊重系統減少動態偏好，無 WebGL 時提供背景替代。
- 移除 BEHIND THE NUMBERS／YOUR MUSIC. YOUR PRIVACY. 獨立區塊；入口保留簡短的本機分析提示。
- 個人化聲波環顯示目前範圍最常聽的前三首歌曲與前三位歌手，依時數排序，匯入、年份及手動排除後同步更新。
- 移除各區塊分享按鈕，統一於廣告上方「分享出去」顯示多張本機產生的圖片，每張提供分享及下載。右上切換直式 1080×1350／正方形 1080×1080；聲波等比例縮放。內容隨篩選、排序與明細更新，年份寫入標題，排除條件不出現在圖片上。底部只保留 TripEZGo Icon 與 TripEZGo.com。
- 網站名稱為 TripEZGo，左上品牌旁為「← 返回」官網連結。頁尾使用 ZhgChg.Li 官方 SVG 署名 Logo，右側為 Made for fun, with love. 與 Spotify 無關聲明。
- 不提供登入或永久保存；個人資料不納入原始碼／建置產物。
- 下載教學直接展開於「獲取播放紀錄」按鈕下方；展開後同一按鈕改為「匯入播放紀錄」並開啟選檔。聲波中央顯示「拖曳播放紀錄至此」。移除不需自行解壓縮的額外說明，Podcast 一律排除。
- 歌手排行榜及歌曲明細中的歌手名稱可開啟歌手明細：總時數／次數、首次／末次聆聽、逐年分布、聽過的歌曲清單、日期篩選、排除歌手及圖片分享。歌手依完整名稱精確分組，避免相似名稱混入。

- 五語系：繁中、英文、簡中、日文、韓文。根目錄初次依瀏覽器語言選擇；各語言有獨立靜態網址，頁尾提供完整語言切換。切換保留分析，原始歌名／歌手不翻譯。
- 正式網址為 https://sound.tripezgo.com/，使用 GitHub repo TripEZGo/tripezgo-sound 和 GitHub Pages Actions 部署。Cloudflare sound CNAME 指向 tripezgo.github.io（DNS-only），啟用 HTTPS。
- SEO：每語言預先產生完整入口內容與 title／description、canonical、雙向 hreflang、OG／Twitter metadata、JSON-LD，提供 sitemap 和 robots。
- 頁首、入口與頁尾使用與內容一致的最大寬度；頁尾用 Grid 固定成作者／聲明列及置中語言列。
- 下載教學第一步只保留「前往 Spotify 隱私設定 ↗，」；第二步合併為「捲動至『下載你的資料』選擇『長期串流播放記錄』。」
- 主站最後新增主題色「旅行 x 音樂」外部連結，以新視窗前往音樂站；從獨立 worktree 發布，保留原主站工作區既有修改。
